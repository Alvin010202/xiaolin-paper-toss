# 小林这球必须进

办公室主题的纸团投篮网页小游戏。主角小林，拖动纸团、松手，把纸团投进垃圾桶。

- 20 个手工设计关卡，分为工位区、茶水间、会议室三个场景
- 每日挑战：按北京时间每天换一个场地，10 球连击计分
- 朋友头像：预置人物 + 玩家在本机导入的人物（投手、观众、转椅嘉宾、每日主持人）
- 本地存档、成绩卡（PNG）下载与分享、完整的暂停 / 结算 / 重来流程
- 主要面向手机浏览器，也支持电脑鼠标

纯静态网站：没有服务器、没有账号、没有第三方统计；运行时不请求任何外部资源（字体用系统字体，音效由程序合成），所以不需要 VPN，放到任何静态托管上都能打开。

## 技术栈

TypeScript · Vite · Phaser 3（画面）· Phaser 内置的 Matter 物理 · 原生 DOM/CSS（菜单、弹窗、头像管理）· localStorage（存档）· IndexedDB（导入的头像）· Vitest（规则与物理测试）· playwright-core + 本机 Chrome（端到端测试）

## 安装与启动

需要 Node.js 20 以上（开发时使用 Node 24）。

```bash
npm install          # 安装依赖（按 package-lock.json 锁定版本）
npm run dev          # 开发模式 http://localhost:5173
```

## 测试与构建

```bash
npm run typecheck    # 类型检查
npm test             # 单元测试 + 实际物理测试（命中判定、计分、每日日期、存档、20 关可解性）
npm run build        # 类型检查 + 生产构建，输出到 dist/
npm run preview      # 预览生产构建 http://localhost:4173（--host 已开启，同一局域网的手机也能访问）
npm run test:e2e     # 端到端测试（先 build；需要本机安装 Google Chrome），截图在 test-results/
npm run solve        # 重新搜索并验证所有关卡的可行投掷（改关卡后运行，约 5～7 分钟）
```

## 静态部署

`npm run build` 生成的 `dist/` 就是完整网站，使用相对路径，可以放在任意域名或子目录下。

- **GitHub Pages**（已准备好配置）：把本目录推到 GitHub 仓库的 main 分支，仓库 Settings → Pages → Source 选 “GitHub Actions”，`.github/workflows/deploy.yml` 会自动测试、构建、发布。大陆一般不开 VPN 能打开，但速度和稳定性不保证。
- **大陆访问最稳定**：腾讯云 COS / 阿里云 OSS 的静态网站托管，把 `dist/` 里的文件全部上传即可。使用自己的域名需要 ICP 备案。
- **其他**：Netlify、Cloudflare Pages、Vercel 等都可以直接托管 `dist/`（注意 `*.vercel.app` 在大陆无法访问）。

正式网址：构建时设置环境变量 `VITE_PUBLIC_URL=https://你的网址/`，成绩卡和“复制链接”会显示它；不设置时，在公开网址上访问会自动使用当前页面地址；在本机（localhost / 局域网 IP）运行时不显示任何网址，也不生成二维码。

## 朋友头像

### 开发者预置（随网站发布）

1. 把头像图片放进 `public/avatars/`（JPEG / PNG / WebP，建议正方形 256×256 以上）
2. 编辑 [`src/characters/characters.config.ts`](src/characters/characters.config.ts)，复制一个条目，修改：
   - `id`：英文唯一标识
   - `nickname`：昵称
   - `avatar`：`'avatars/文件名.jpg'`
   - `accentColor`：衣服颜色
   - `cheerLines` / `missLines`：命中 / 没进时的台词
3. 替换头像：同名文件直接覆盖

第一位必须是主角小林（`id: 'xiaolin'`，默认投手）。目前四位朋友（工位搭子、咖啡续命、会议记录员、摸鱼专家）是**占位角色**，不是真实姓名，等你提供朋友的昵称和头像后替换。头像留空或加载失败会自动显示原创占位头像。

**人物台词**也在 `characters.config.ts` 里编辑；玩家导入的人物使用同文件里的 `DEFAULT_CHEER_LINES` / `DEFAULT_MISS_LINES`。

### 玩家本地导入

游戏内“朋友头像”页面：导入 JPEG / PNG / WebP（8 MB 以内），拖动平移、滑块或滚轮缩放、方形裁剪（圆形预览），自动缩小为 256×256 后保存在浏览器 IndexedDB。可以改昵称、换头像、删除、选为投手。照片只在本机浏览器里处理，不会上传。

人物用途：投手（选中的人）、底部观众（命中鼓掌、没进惊讶并说台词）、转椅嘉宾（部分会议室关卡里按固定路线移动的障碍）、每日挑战主持人（按天轮换）、成绩卡上的头像和昵称。人数不足时会复用。

## 关卡配置

所有关卡是数据，不复制业务代码：

- [`src/levels/levels.ts`](src/levels/levels.ts)：20 关。每关包含 `id`、`name`、`scene`、`throwPoint`（投掷点）、`bin`（桶底中心、可选高度、可选移动路线）、`target`（目标进球数）、`staticObstacles`（静态障碍）、`dynamicObstacles`（转椅嘉宾）、`windZones`（风力区域）、`hint`（提示）、`difficulty`（难度说明）、`newMechanic`（新机制首次出现时的一句话提示）
- [`src/levels/dailyTemplates.ts`](src/levels/dailyTemplates.ts)：每日挑战的已验证场地模板
- 坐标：逻辑画面 540×960，地面顶部 y = 860；矩形障碍的 x、y 是中心点
- 修改布局后运行 `npm run solve`：工具用游戏同一套物理（同一份 Matter 代码、同样的固定步长）枚举出手角度、力度和（移动关卡的）出手时机，把可行投掷写入 `src/levels/solutions.json`；`npm test` 会在全新物理世界里重放这些投掷确认命中，并检查移动物体不会和桶或障碍重叠

机制引入顺序：工位区（第 1～6 关）近距离 → 远距离 → 高桶 → 墙壁反弹 → 桌面遮挡 → 综合；茶水间（第 7～13 关）顺风 → 逆风 → 高平台 → 窄缝 → 上升气流 → 组合；会议室（第 14～20 关）移动垃圾桶 → 转椅嘉宾 → 白板反弹 → 桌上移动桶 → 多机制组合。

## 规则

### 操作与判定

- 在纸团周围的虚线圈里按住，往反方向拉；拉得越长力度越大（有上下限），拉太短松手不发射
- 预览只显示飞行前段的轨迹点，不显示落点
- 出手后锁定操作；飞出画面、静止 0.7 秒或超过 7 秒判定本次结束，随后出现下一枚纸团
- 触摸被取消、窗口失去焦点、暂停时，未完成的拖动会被取消
- 垃圾桶有实际的桶壁、桶底和桶口感应区。命中判定是明确的状态流程（`src/rules/hitDetector.ts`）：纸团必须从桶口上方向下越过桶口并碰到感应区，然后在桶内连续停留 0.3 秒才计分；每次投掷最多计分一次；侧面擦碰不算；没经过桶口出现在桶内（从桶底穿入）判为无效
- 没有任何吸附或修正轨迹的逻辑

### 闯关

每关 5 次投掷，达到目标立即过关。过关 1 星，剩余 ≥1 次 2 星，剩余 ≥2 次 3 星。保存每关最高星级，较差成绩不会覆盖。通过一关解锁下一关。

### 每日挑战

- 日期按 Asia/Shanghai（北京时间）计算，零点换日，与设备时区无关
- 种子 = FNV-1a 哈希（`规则版本:日期`），用它从已验证模板中选当天场地、并轮换主持人；同一天的场地、物理参数、规则完全相同
- 每轮 10 球：命中 100 分；连续命中从第 2 球起加成 +25、+50、+75，之后每球封顶 +100；没进清零连击
- 当天可重复挑战，只保存本机最高分；记录日期、模板标识、种子、规则版本（`daily-v2`；物理或模板改动时升级，旧版本当天的成绩不与新版本混算）
- 每次开局（含重来）动态障碍的时间相位都从 0 开始
- 没有全球或好友排行榜

### 存档

- localStorage 键 `xiaolin-paper-toss:save`，版本号 2，带默认值和逐项校验
- 只保存：设置（声音、减少动画）、各关最高星级、所选投手、每日挑战记录（最近 60 天）、是否看过新手演示
- 数据损坏时保留能读取的部分；完全无法读取时重新开始；旧版本（原型阶段的 v1 格式）自动升级
- 浏览器禁用存储时游戏照常可玩，并提示“本次进度不会保存”
- 导入的头像存在 IndexedDB，不进 localStorage
- 设置页“重置存档”会列出将删除的数据并要求确认，可选择是否同时删除导入的头像

## 目录结构

```
src/
  config/       游戏参数（尺寸、物理、手感、规则）、正式网址
  physics/      物理世界、路线运动、拖动与轨迹预览、单次投掷流程
  rules/        命中判定状态流程、计分、一局的规则状态
  levels/       关卡数据、每日模板、验证结果 solutions.json
  daily/        北京时间日期、种子、当天挑战

  ui/           DOM 页面（首页、关卡、每日、头像、设置、游戏 HUD/暂停/结算/分享）

```

## 已知限制

- 物理在同一浏览器内可复现；不同浏览器、设备的浮点计算可能有极细微差别，因此每日挑战不保证跨设备结果完全一致（所以也没有排行榜）
- 关卡难度由验证工具的“命中参数占比”粗略衡量，并非真人大规模测试；不少关卡存在“平抛撞进桶后壁”的打法
- 第一次加载需要下载约 360 KB（gzip）的脚本，主要是 Phaser
- 只做了静态头像，人物动作由身体姿势、头像缩放和对话气泡表现
- 端到端测试只在 Chrome（桌面、手机模拟）上实际运行；Safari / 微信内置浏览器未实测
- 声音需要用户首次点击后才会启用（浏览器限制）
- 四位预置朋友是占位角色，等待真实朋友信息
