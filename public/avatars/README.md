# 头像图片目录

把朋友的头像放在这里，然后在 `src/characters/characters.config.ts` 里填写 `avatar: 'avatars/文件名'`。

- 格式：JPEG、PNG、WebP 均可
- 建议正方形、256×256 以上；不是正方形时会自动居中裁成正方形（不会拉伸变形），游戏里以圆形显示
- 替换头像：用同名文件直接覆盖即可
- 文件缺失或损坏时游戏会自动显示占位头像，不会出现破图

当前文件：

| 文件 | 说明 |
| --- | --- |
| `xiaolin.png` | 主角小林的圆形头像来源（256×256），由项目所有者提供的小林图片裁出 |
| `xiaolin-full.png` | 小林全身图，首页插画使用 |

注意：这个目录里的图片会随网站一起公开发布，请只放已获得本人同意公开的头像。
